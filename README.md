# Overview
This repository can be found at https://github.com/NEFSC/READ-SSB-Lee-RFAdataset

This repository holds code to assemble ownership data for RFAA analysis.  
Please see [here](/documentation/output_documentation/output_data_description.md) for documentation on the dataset.

Please see the [project template repository](https://github.com/NEFSC/READ-SSB-Lee-project-template/) for a few notes on getting the stata code to run. 

Please help make this a valuable up-to-date resource.  Look [here](https://github.com/NEFSC/READ-SSB-Lee-WorkingEfficiently), if you'd like to contribute. 

# How to run

The file ``R_code/wrapper_extraction.R`` will extract and process data. There is sample code to push to oracle.

Stata code is in the repository, but no longer maintained after the 2026 data release.

# Sample Code
You can find sample stata code in  /stata_code/sample.  You can find Rmarkdown documents that use the RFA data at are collected in [this repository](https://github.com/NEFSC/READ-SSB-Lee-regulatory-analyses).  

The [2025 Herring SIR](https://github.com/NEFSC/READ-SSB-Lee-regulatory-analyses/blob/main/Herring_SIR2025-2027/writing/SIR2025_Economic_Impacts.Rmd), starting around line 459,
and the [2025 Black Sea Bass Specs](https://github.com/NEFSC/READ-SSB-Lee-regulatory-analyses/blob/main/BSB_Specs2025/writing/SIR2025_Economic_Impacts.Rmd), starting around line 134, are two recent examples of documents that use the RFA data directly.
